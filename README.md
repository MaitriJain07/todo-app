# Todo App

A simple Todo App built for the IITM BS workshop:
"Future of Software Development with LLM : Spec Driven Development"

## Branches

- main → base app
- vibe_coded_submission → implemented using vibe coding
- sdd_submission → implemented using spec driven development

## Features

- Add tasks
- Delete tasks
- Mark tasks complete
- Dark mode
- Local storage
- Task filtering
